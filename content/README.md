# Структура учебных материалов

Материалы хранятся сначала по группе, затем по дисциплине. Если одна дисциплина встречается у группы в разных семестрах, внутри неё добавляется папка семестра:

```text
content/
  groups/
    <group-id>/
      <discipline-id>/
        [semester-<number>/]
          <topic-id>/
            <material-id>.html
```

Например, для МДК 04.02 отдельные варианты уже заведены здесь:

- `groups/1eo-25/mdk-04-02/semester-1/` — группа 1ЭО-25, 1-й семестр;
- `groups/1eo-24/mdk-04-02/semester-3/` — группа 1ЭО-24, 3-й семестр.

Их названия совпадают, но это самостоятельные записи в `materials.json` с разными списками тем и материалов. Не переносите материал между ними, пока не проверили, что он подходит обоим учебным вариантам. Если материал действительно общий, его можно будет подключить из одного файла.

Группы и список их дисциплин задаются в корневом `materials.json`. Путь для конкретной дисциплины указан в поле `contentPath`, а путь к каждому HTML-файлу материала — в поле `file`. После изменения каталога запускайте `build-catalogue.cmd` для обновления локального предпросмотра.

Папки дисциплин создаются только внутри папок конкретных групп. Если у одной группы материалы по дисциплине отличаются в разных семестрах, добавляйте семестр внутрь папки этой дисциплины.
