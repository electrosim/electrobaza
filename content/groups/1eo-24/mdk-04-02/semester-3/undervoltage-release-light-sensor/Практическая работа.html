Расчётная часть

Пример для варианта 8. Для своего варианта подставьте данные таблицы 1; порядок расчёта не меняется.

1. Цепь расцепителя

  • Iн = Pн / Uн
  • Rк = Uн2 / Pн
  • Uотп = 0,5 · Uн
  • Uвкл = 0,85 · Uн
  • Iн = 0,125 А.
  • Rк = 192 Ом.
  • Uотп = 12 В.
  • Uвкл = 20,4 В.
  • При 40 °C: R = 207,4 Ом.
  • Uотп = 12,96 В (+8 %).
  • При lр = 50 м, S = 1,5 мм²:
  • ΔU = 0,146 В.
  • Uкат = 23,85 В, что выше 20,4 В.
  • PΣ = 4,7 Вт.
  • IΣ = 0,196 А.
  • Блок 24 В на 1,25 А подходит.

2. Датчик освещённости

  • R1 = Rф(Eвкл) · (Uпит / Uпор − 1)
  • Uвых = Uпит · Rф / (R1 + Rф)
  • Uотк = (1 − h) · Uвкл
  • При Eвкл = 150 лк: Rф = 5,5 кОм.
  • R1 = 5,5 · 3,8 = 20,9 кОм.
  • Принимаем R1 = 20 кОм.
  • Порог 2,5 В: Rф = 5,26 кОм.
  • Eвкл ≈ 164 лк.
  • При h = 25 %: Uотк = 1,875 В.
  • Rф = 3,70 кОм.
  • Eотк ≈ 258 лк.
  • Гистерезис 94 лк.

Рассчитайте Uвых для своего R1 по таблице 2 и постройте график.

3. Осветительная линия

  • Iл = Pл / Uс
  • ΔU = 2 · ρ · L · Iл / S
  • ΔU, % = 100 · ΔU / Uс
  • Iл = 13,04 А.
  • Результаты — в таблице 3.
  • Принимаем 4 мм².
  • Лучше 6 мм² с запасом.
  • Автоматический выключатель B16.
