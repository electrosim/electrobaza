Последовательное соединение

При последовательном соединении резисторов через каждый элемент проходит один и тот же ток. Общее сопротивление равно сумме сопротивлений:

R = R₁ + R₂ + … + Rₙ

Параллельное соединение

При параллельном соединении напряжение на ветвях одинаково. Для двух резисторов общее сопротивление вычисляют по формуле:

R = (R₁ × R₂) / (R₁ + R₂)

Общее сопротивление параллельного соединения меньше сопротивления наименьшего из резисторов.
